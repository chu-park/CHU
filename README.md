# CHU

discord.py 기반 슬래시 커맨드 봇. 여러 서버에서 동시 사용 가능하며, 서버별 설정/데이터는 `data/<guild_id>.json`에 저장됩니다.

## 실행 방법

1. 의존성 설치
   ```
   pip install -r requirements.txt
   ```
2. `.env` 파일 생성 후 봇 토큰 입력
   ```
   DISCORD_BOT_TOKEN=여기에_토큰
   ```
3. Discord 개발자 포털에서 봇의 **Server Members Intent**를 켜주세요. (역할 부여/멤버 조회에 필요)
4. 실행
   ```
   python bot.py
   ```

## 관리자 권한

`@관리` 또는 `@운영` 역할을 가진 멤버가 관리자로 취급됩니다. 서버에 두 역할 중 하나 이상을 만들어두어야 관리자 전용 명령어를 사용할 수 있습니다.

## 기능

### 가입신청

- `/가입신청채팅방고정`: 실행한 채널에 가입신청 임베드(+ "신청하기" 버튼)를 전송하고 고정합니다. 기존에 고정된 신청 메시지가 있으면 자동으로 교체됩니다.
- `/가입신청서설정`: 승인채널/승인역할을 지정하고(옵션), 버튼을 통해 신청서 제목/설명/질문 항목(최대 5개)을 수정합니다.

동작 방식:
1. 유저가 "신청하기" 버튼을 누르면 설정된 질문으로 구성된 팝업(Modal)이 뜹니다.
2. 제출하면 설정된 승인채널에 신청 내용과 승인/거절 버튼이 담긴 메시지가 올라갑니다.
3. 관리자가 승인하면 설정된 역할이 자동 부여되고, 거절하면 신청자에게 DM으로 안내됩니다.
4. 처리 대기 중인 신청이 있는 유저는 중복 신청할 수 없습니다.
