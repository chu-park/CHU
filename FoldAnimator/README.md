# 폴드 애니메이션 (FoldAnimator)

갤럭시 Z 폴드에서 **아이폰 듀오처럼 접고 펼칠 때 화면이 이어지는 애니메이션**을 보여주는 Kotlin 안드로이드 앱입니다.

## 어떻게 보이나요

- **펼칠 때**: 커버 화면 배경이 흐려지고 커지며 어둡게 가라앉아 “화면을 통과해 사라지는” 느낌 →
  메인 화면이 켜지면 흐리고 늘어난 상태에서 힌지 각도를 따라 점점 선명하게 제자리로 돌아옵니다.
- **접을 때**: 같은 과정이 거꾸로 진행됩니다.
- 시간으로 재생되는 애니메이션이 아니라 **힌지 각도에 직접 묶여 있어** 손으로 여는 속도를 그대로 따라갑니다.

## 기능

- 애니메이션 **켜기/끄기** (끄면 일반 배경화면처럼 보임)
- **힌지 각도별 화면 표시 %** – 0°·30°·60°·90°·120°·150°·180°마다 메인 화면을 몇 % 선명하게 보여줄지 설정
  (프리셋: 기본 / 선형 / 빠르게 선명 / 끝까지 흐리게, 그래프 표시)
- 커버 화면이 완전히 사라지는 각도 설정
- 블러 강도, 늘어남(확대), 어두워짐, 부드러움 조절
- 배경 사진 선택 (기본 그라데이션 이미지 제공)
- 커버/메인 화면 실시간 미리보기 (실제 힌지 각도 연동 또는 시뮬레이션)

## 동작 원리

`WallpaperService` 기반 **라이브 배경화면**입니다. 홈 화면이 보이는 동안 `Sensor.TYPE_HINGE_ANGLE`(힌지 각도)를 읽고,
현재 화면이 커버인지 메인인지에 따라 표시 비율을 계산해 `RenderEffect` 블러 + 확대 + 비네트로 매 프레임 그립니다.
화면 위에 창을 띄우지 않으므로 터치를 막지 않고, 커버↔메인 전환 순간에도 바로 해당 각도 상태로 그려 깜빡임을 줄입니다.

### 한계

- 홈 화면(배경화면이 보이는 곳)에서 동작합니다. 앱 아이콘은 One UI 런처가 그리기 때문에 함께 움직이지 않습니다.
- 커버↔메인 화면이 바뀌는 순간의 아주 짧은 검은 화면은 기기가 처리하는 부분이라 앱에서 없앨 수 없습니다.
  (전환 근처 각도에서 배경을 어둡게 해 자연스럽게 이어지도록 했습니다.)

## 빌드 & 설치

**GitHub Actions (PC 없이)** – 이 폴더가 바뀌어 푸시되면 `FoldAnimator APK` 워크플로가 APK를 빌드합니다.
GitHub → Actions → 최신 실행 → Artifacts의 `FoldAnimator-apk` zip을 받아 압축을 풀고 APK를 설치하세요.

**Android Studio** – `FoldAnimator` 폴더를 열고 폰을 연결해 실행합니다.

## 사용법

1. 앱 실행 → **배경화면으로 설정하기** → 적용 (홈 화면 또는 홈+잠금화면)
2. 원하는 사진 선택, 효과와 각도별 % 조절 — 바꾸는 즉시 배경화면에 반영됩니다.

요구 사항: Android 12 이상, 힌지 각도 센서가 있는 폴더블 기기.
