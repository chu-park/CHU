# 폴드 애니메이션 (FoldAnimator)

갤럭시 Z 폴드 시리즈에서 **접고 펼칠 때 애니메이션**을 재생하는 Kotlin 안드로이드 앱입니다.

## 기능

- **켜기/끄기** – 스위치 하나로 애니메이션 서비스를 켜고 끕니다. (알림의 “끄기” 버튼으로도 가능)
- **힌지 각도별 화면 표시 %** – 0°·30°·60°·90°·120°·150°·180° 지점마다 화면을 몇 % 보여줄지 슬라이더로 설정. 사이 각도는 선형 보간.
  - 프리셋: 기본 / 선형 / 빠르게 열림 / 늦게 열림
  - 그래프와 실시간 힌지 각도 표시, 미리보기 화면
- **스타일** – 힌지 커튼(가운데에서 양옆으로 열림), 원형 아이리스, 페이드
- **재생 시점** – 펼칠 때 / 접을 때 / 접은 뒤 커버 화면 열림 효과 / 빠르게 펼쳐도 처음부터 재생
- 부드러움(속도), 모서리 둥글기 조절
- 재부팅 후 자동 시작

## 동작 원리

일반 앱은 One UI의 화면 전환 애니메이션을 직접 바꿀 수 없기 때문에, 다음 방식으로 구현했습니다.

1. 포그라운드 서비스가 `Sensor.TYPE_HINGE_ANGLE`(힌지 각도)와 기본 디스플레이 변화(커버 ↔ 메인 화면 전환)를 감시합니다.
2. 접기/펼치기가 감지되면 `TYPE_APPLICATION_OVERLAY` 창을 띄우고, 설정한 곡선에 따라 “각도 → 표시 %”로 마스크를 엽니다/닫습니다.
3. 손을 멈추거나 끝까지 펼치면 마스크를 100%로 열고 즉시 창을 제거합니다(터치를 계속 막지 않음).

### 한계

- 애니메이션이 재생되는 0.3~0.5초 동안은 터치가 막힐 수 있습니다(안드로이드 12+ 보안 정책).
- 상태바·내비게이션바·잠금화면 위에는 그려지지 않습니다.
- 메인 화면이 켜지는 시점은 기기가 정하므로, 아주 빠르게 펼치면 “빠르게 펼쳐도 처음부터 재생” 옵션이 시간 기반으로 대신 재생합니다.

## 빌드 & 설치

**방법 1 – GitHub Actions (PC 없이)**
이 폴더가 바뀌어 푸시되면 `FoldAnimator APK` 워크플로가 APK를 빌드합니다.
GitHub → Actions → 최신 실행 → Artifacts의 `FoldAnimator-apk`를 내려받아 폰에서 설치하세요.
(출처를 알 수 없는 앱 설치 허용 필요)

**방법 2 – Android Studio**
`FoldAnimator` 폴더를 Android Studio로 열고 폰을 연결해 실행합니다.

## 처음 실행 시

1. 앱에서 스위치를 켜면 **다른 앱 위에 표시** 권한 화면으로 이동 → 허용
2. 알림 권한 허용 (상시 알림이 있어야 백그라운드에서 동작)
3. 권장: 설정 → 애플리케이션 → 폴드 애니메이션 → 배터리 → **제한 없음** (One UI가 서비스를 종료하지 않도록)

요구 사항: Android 11(API 30) 이상, 힌지 각도 센서가 있는 폴더블 기기.
